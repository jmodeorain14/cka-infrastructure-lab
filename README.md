# CKA Infrastructure Lab

AWS EC2 infrastructure for Certified Kubernetes Administrator (CKA) preparation.

## Overview

This repository documents the AWS EC2 infrastructure used to provide an Ubuntu Linux environment for CKA training.

The infrastructure was initially provisioned manually via the AWS EC2 GUI, and will later be provisioned using Terraform.
